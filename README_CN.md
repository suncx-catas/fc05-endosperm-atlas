# 单一胚乳的分化代谢轨迹：椰子液态与固态胚乳发育转换的多组织代谢图谱

**单位：** 中国热带农业科学院椰子研究所（CRI-CATAS），海南文昌  
**目标期刊：** *Journal of Agricultural and Food Chemistry*（JAFC）  
**版本：** FC-05 V11.1（2026-06-18）

## 核心亮点

- **双平台多组织代谢图谱**：整合文椰 5 号（W5）、文椰 6 号（W6）与海南高种（CK）共 12,947 个代谢特征——椰子水采用靶向 UPLC-MS/MS（624 种代谢物，6 个发育期），椰肉采用非靶向 UHPLC-Q-TOF-MS（12,323 个特征，3 个发育期）。
- **液–固组织代谢方向逆转**：12 个共有代谢物大类中有 8 类在液态椰子水与固态椰肉之间呈现相反的发育变化趋势，与约 7 月龄的胚乳细胞化节点高度协同。
- **黄酮与单宁极性反转**：黄酮类与单宁类在椰子水中显著耗竭（log₂ FC = −1.42 与 −3.08），而在固态椰肉中主动富集（W6 中 +0.16 与 +0.55）；氨基酸、核苷酸和有机酸则呈相反轨迹。
- **可落地的采收优化日历**：基于 173 种风味与营养关键化合物的时序变化，量化给出三大用途的最佳采收窗口——鲜饮椰子水（6–8 月龄，糖度峰值 7.5–8.2 Brix°）、功能型椰子水（10–12 月龄，游离氨基酸峰值）与初榨椰子油（12 月龄，脂质与酚类峰值）。

## 摘要

椰子水与椰肉同源于单一胚乳组织，成分却截然不同：前者为富糖饮品，后者为高油固态果肉。本研究结合靶向 UPLC-MS/MS（椰子水，624 种代谢物，6 个时期）与非靶向 UHPLC-Q-TOF-MS（椰肉，12,323 个特征，3 个时期）系统描绘了液态向固态胚乳转变的代谢轨迹。结果显示，12 个共有化合物大类中 8 类在两组织间呈相反变化方向，其中黄酮与单宁在椰子水中下降、在椰肉中上升，而氨基酸、核苷酸和有机酸则相反。基于 173 种风味与营养成分的动态图谱，本研究提出了面向品种的精准采收优化指南，为椰子分子育种与工业品质管理提供了定量代谢基准。
